# Support

## Playing

The deployed build is at <https://battleship2-xne9.vercel.app/>. No install,
account, or network connection to us is required; progress is stored in your
own browser.

## Questions

1. Check the [wiki](https://github.com/aackad21/battleship2/wiki), which covers
   the rules, the variants, the AI commanders, the abilities, and common
   problems.
2. Check [TESTING.md](TESTING.md) for known behaviour and the defect register.
3. If neither answers it, open an issue using the templates.

## Problems

- Gameplay defects: open a bug report and include the mode, the variant, the
  commander, reproduction steps, and any browser console output.
- Security problems: follow [SECURITY.md](SECURITY.md) and report privately.
- Contributing a fix: see [CONTRIBUTING.md](CONTRIBUTING.md).

This is a hobby project maintained by one person, so responses are best effort
and there is no service-level commitment.
